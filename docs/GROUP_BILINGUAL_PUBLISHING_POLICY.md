## قاعدة المالك الإلزامية
كل إضافة أو تعديل عربي في البوابة الرئيسية أو مشاريع الإسكان أو الفنادق يجب أن يقابله في نفس التغيير نص إنجليزي **كامل ورصين** يشمل العنوان والملخص والمتن والفصول والأوصاف وروابط المشاركة وبيانات SEO. لا تُعرض نسخة `en` بالمتن العربي أو برسالة "الترجمة غير متوفرة" بوصفها صفحة نهائية.

### متطلبات كل تغيير
- العربية هي المرجع التحريري؛ الإنجليزية ترجمة دقيقة مستقلة الصياغة تحافظ على حقائق النص ولا تضيف ادعاءات.
- استخدم `lang="ar" dir="rtl"` للعربية و`lang="en" dir="ltr"` للإنجليزية، مع ترجمة العناوين والأزرار وبيانات الوصف.
- يُمنع دمج أي تغيير يترك نصًا إنجليزيًا ناقصًا، أو رابطًا معطّلًا، أو شعارًا افتراضيًا بدل الأصل الرسمي.
- كل محتوى عقاري يحتاج توثيق اسم المشروع والحالة والموقع، والموافقة على استخدام الصور والشعارات.
- معايير الجودة تشمل اكتمال الفقرات، سلامة الترجمة، التوافق الثقافي ودقة الأسماء، لا مجرد وجود نص في حقول English.
- يتم تجهيز الترجمات أثناء التحرير باستخدام مساعد معتمد، مع مراجعة المالك للنسختين. **لا يوجد حاليًا مترجم تلقائي موصول** بخط أنابيب النشر.
- لا دمج في `main` ولا نشر على GitHub Pages قبل الاعتماد الصريح.
